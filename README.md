# Site scientifique — Spondylarthrite ankylosante et départ de sprint

Architecture web statique prête à personnaliser et publier gratuitement sur GitHub Pages.

## Contenu du dossier
- `index.html` : toutes les sections du site et les emplacements de contenu.
- `style.css` : identité visuelle scientifique bleu, responsive.
- `script.js` : menu hamburger et navigation active.
- `assets/` : dossier destiné aux photographies et schémas.

## Personnaliser
Ouvrez `index.html` avec un éditeur de texte (Visual Studio Code, par exemple) et remplacez les textes indicatifs par votre contenu.
Pour ajouter une image, déposez-la dans `assets/` avec le nom indiqué sous l'emplacement visuel, ou modifiez le chemin `src` dans le HTML.
Pour les graphiques, exportez vos figures en PNG ou SVG et utilisez-les comme images, ou remplacez les emplacements prévus.
Pour une vidéo, remplacez le bloc vidéo par un lecteur HTML5 ou un code d'intégration fourni par votre plateforme.

## Publier gratuitement avec GitHub Pages
1. Créez un compte sur https://github.com.
2. Créez un dépôt public, par exemple `etude-spondylarthrite-sprint`.
3. Envoyez tous les fichiers et dossiers de cette archive à la racine du dépôt. `index.html` doit se trouver à la racine.
4. Ouvrez **Settings → Pages**.
5. Dans **Build and deployment**, sélectionnez **Deploy from a branch**, branche `main`, dossier `/ (root)`, puis enregistrez.
6. Patientez quelques minutes : GitHub affichera l'adresse du site dans la rubrique Pages.

## À vérifier avant diffusion
- Remplacer tous les textes indicatifs.
- Remplacer les exemples de tableau et de graphique par les données réelles.
- Ajouter les légendes, sources et crédits des illustrations.
- Vérifier les droits de diffusion des médias et le consentement des personnes identifiables.
- Ne publier aucune donnée personnelle ou médicale permettant d'identifier les participants.
- Tester le site sur ordinateur et téléphone.

Aucun serveur, base de données ou abonnement payant n'est nécessaire.
